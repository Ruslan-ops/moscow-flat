# Обновление подборки

Цель: раз в 1–3 дня находить новые объявления и снятые, не пересматривая всё заново.

## Этапы

| Этап | Кто делает | Время | Команда |
|---|---|---|---|
| 1. Сбор новых объявлений | расширение в Chrome + сервер, автоматически | 5–15 мин | `python src/refresh.py seed` |
| 2. Проверка, не сняты ли показанные квартиры | там же, автоматически | ~1 мин на 4 квартиры | (входит в seed) |
| 3. Пересчёт рейтинга и выбор, что смотреть глазами | скрипт | 1–2 мин | `python src/refresh.py prepare [лимит] [макс_цена]` |
| 4. Оценка фото | агенты Sonnet (по 12 квартир на агента) | 2–5 мин | workflow `workflows/photo_review.js` |
| 5. Слияние оценок | скрипт | секунды | `python src/refresh.py merge` |
| 6. Отбор и отчёт | скрипт | 1 мин | `python src/refresh.py build` |

## Почему это дёшево
- Поиск ЦИАН отсортирован по дате. Сбор открывает первую страницу каждого из 12 поисков и идёт дальше, только пока на странице есть объявления, которых ещё нет в базе (максимум 8 страниц). Обычно это 15–30 страниц, а не 300.
- Квартиры, уже оценённые по фото, повторно не смотрятся. Агенты получают только новые объявления с хорошим местом (оценка места ≥ 0,7), сначала с ремонтом «евро/дизайнерский» по фильтру ЦИАН.
- Проверка актуальности открывает только квартиры, показанные в отчёте.

## Что видно в отчёте
- «новое в подборке» — квартира впервые попала в отчёт при последнем обновлении.
- «цена изменилась» — цена отличается от той, что была при первом показе.
- «снято с публикации» — объявление снято; скрыто, пока не включён фильтр «показать снятые».

## Условия
- Запущен сервер: `python collector/server.py serve`.
- Открыт Chrome с расширением MoscowFlatCollector версии 0.6.0. Вход на ЦИАН не нужен.
- Темп: не чаще одного открытия страницы в 12 секунд, без обхода защиты сайта.
